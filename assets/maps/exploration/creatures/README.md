`identity-mapping.json`登记本项目原创中文身份名，不声称腾讯原怪名字或原长相复刻。逐地图完整保留源npc_drop_groups、数量、生命、伤害、防御、速度与掉落池，包括不一致值；美术持物只作外观识别/读招线索，不新增武器范围、技能、阶段或数值。
