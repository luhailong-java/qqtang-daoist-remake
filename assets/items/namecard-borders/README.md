# 五种名片装饰候选

源类别namecardbound有5项。`art.json`记录五种长条首态候选，`inventory/art.json`记录各自256方背包图标，两种表示对应同一源ID，不能相加成10个物品。母图 `namecard-borders-a-v1.png`、`namecard-borders-a-v2.png`和`namecard-icons-b-v1.png`各有独立generation。v2为实际附v1的AI几何修改，editOf保留；裁切和等比导出另有provenance，不冒充新生图。

长条源首帧分别307×22、307×22、305×22、300×22、296×19，导出4倍完整画布，raw offset原值保留；中心抽样alpha0–1。v2去除长流苏、压低皇冠与花簇后，五项可见比例相对源完整帧的偏差约14.86%、8.43%、8.12%、1.99%、2.21%，12501仍超过10%；都未签署几何／视觉通过。新设计的完整宽度、文字区、原尺寸投影和动态状态仍须核实，不做非等比拉伸消警告。

背包图标与原角色头顶／名片装饰是不同资源。显式读取 `res/uiRes/icon/...`作为图标参考；默认首个installed IMG可能是stand，不能只因保存在reference/icons目录就称它是原背包图。图标母图前两个对象越过理想格线，已按实际空隙裁分，alpha>=8不触其裁区边；这是局部必要切片检查，非全量通过。

源12501的stand为3帧、307×22，walk为1帧、115×18，两者字节不同；原始用途／组合／播放时序仍待独立确认。不把长版缩短或复用一张当作短版、全状态和完整动画。其余stand／walk／trigger状态继续制作，九宫格未确认，当前不声明可任意拉伸。全部未运行采用；本机重型验收继续遵守暂停约定。

12501的三态v3母图虽已生成，但低alpha外光在各格边缘达到9–11，未通过alpha>=8边界门槛，导出被拒、帧输出0，没有调低阈值或擦像素放行。强主体不触边也不能据此称全边缘通过；当前首态仍保留v2。具体证据在 `docs/nameplate12501-stand-v3-review.json`，先继续独立短版状态，再集中处理。
