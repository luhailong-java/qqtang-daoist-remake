# 五心祈愿2000：世界原画输入与制作合同

本轮将源24位置的24个独立raster按4批、每批6个明确相位处理。现有0—5旧母图 world-2000-a-v1.png 及旧spec保留，输入阶段计划新路径 a-v2/b-v1/c-v1/d-v1；经实际生成及技术返修后，最终选用见下表和WORLD_2000_DELIVERY_20261112.md，初始计划不代表当前采用；不把源参考像素或旧未采用稿计为新交付。

## 来源事实

用户本地明确路径下 runtime/client-patched/object/thadorn/thadorn65_stand.img 与 thadorn65_walk.img 均只读，与固定ZIP对应member逐字节相同，各109336字节、SHA256 `17817b99d0b1ff95c3ff5dfab6880ba8d941a36a86120ae7d2cbd38f99ef64d2`。没有读取账号DB、日志或配置，没有运行客户端。固定研究ZIP仍为社区修改样本，不能当作腾讯原始版本身份。

源合同/source-recovery-validation-20261112.json 保存ZIP—member—encoded raster—decoded RGBA—PNG SHA链及本地匹配结果。24个encoded raster和实际RGBA+size均各自不同，无别名复用。所有24源PNG均已按6张一批重新解码，4张 source-phases-a/b/c/d.png 板和 source-components-a/b/c/d.json 测量表齐备。每帧在alpha>=16时恰5个分离心组件；B/C/D部分几何中心相同，但像素SHA不同，不按近似画面合并。

## 原创造型与生成约束

实际查看源四板、既有inventory五心祈愿和邮件/组队主参考。延续粉珊瑚玉心、暖金细边和嵌入边缘的小金云卷。每帧恰5颗独立心，空中心与各心间隙保留；不得添加实体环/绳、轨迹线、散光或新粒子改变alpha包络。每相位五心的实际位置、大小与面转角按对应源板及source-components测量表；不能套用背包的单一静态排列。

仅内置image_gen，项目目标由config/image-generation.json读取；工具没有model/quality选择器，actualModel/actualQuality必须null，逐母图保存exact提交prompt、实际引用用途/SHA、宿主source及真实尺寸。原生实际返回画布与目标请求分别记录；裁格按真实alpha检查，不假定1536×1024必然返回。

导出保持source logical/rawOffset、density4和原帧序，只按source alpha包络等比缩放、X居中/Y底对齐；预乘alpha LANCZOS，不做程序重绘、镜像、拉伸或形变。比例大于10%必须真实AI修图后再检查；技术比例通过也不等于用户视觉通过。独立world-2000-art.json，所有新帧视觉/geometry/accepted/runtime仍false/pending，不修改全族采用清单。
