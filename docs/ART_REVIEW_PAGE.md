# 美术制作检查页

`art.html`、`src/art-review.js`、`src/art-review.css`新增内部检查入口，复用真实资产清单，分别查看基础道具、对局拾取物、技能图标、食物、锻造、仙灵卡、20静态人物、8临时形态、角色原画/姿态、探险实体、糖泡/火焰/护体序列。米白、深青与棋盘背景用于检查透明边缘；原画比例保持，来源详情以文本呈现。自有新名字优先显示，原始名字保留在来源详情；账号itemId、场景sceneId与角色槽位编号不混用。

另加入任务／关系／货币卡、platform功能道具及名片装饰长版、短版、背包图标。长条独占整行，使用 `src/art-review-nameplates.css`，不把307×22首态挤进方格缩略图；有已知比例警告的条目标为未通过。长／短／图标表示同一物品，不能重复算源ID，未完成的连续状态仍留在制作账。

大人物原图每页最多4张，图标每页24件，并按页替换DOM与懒载入；避免一次显示整套4096兼容原图。分页、搜索和类别切换仍待实际浏览器检查，不把内存策略的代码存在算作性能通过。

序列按源帧offset与宽高计算共享显示范围，不逐帧包围盒吸附。明确空帧保持为空白，重复帧指向原已选图片。80/120/180ms只用于人工检查节奏，不当作原版播放数据；默认暂停，换类别、切序列、隐藏页面时停止，只有手动播放才启动动画。不是对局时序实现，也未自动采用任何候选。
