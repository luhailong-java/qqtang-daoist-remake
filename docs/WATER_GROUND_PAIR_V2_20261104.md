# 水面地砖 5001、5019 修订

[生成记录](../assets/maps/water/ground-pair-v2.png.generation.json)登记内置生图原画为 1536×1024 RGB，SHA-256 为 `00dab7a4c5ffba953d98f7506b362b77eeb082f37a20b380dbb8a103e39a0642`。宿主未披露实际型号和质量。导出把两块原画的 640×640 裁区用 Lanczos 等比缩小到 160×160。纯裁切后四边之间仍有色差，遂以这两块裁区本身的 RGB 在 12 像素范围内做边缘混合。先取两张图左、右边缘逐行平均为共同曲线，再以相同方式取第一遍结果的上、下边缘逐列平均。每遍边缘权重为 `1 − smoothstep(clamp(d / 12, 0, 1))`，`d` 为该遍距最近边的像素距离。两遍完成后四舍六入五成双取整。中心区保留原裁区色彩，最终导出不透明 RGBA。这个后处理只用于拼接两张新绘素材，没有使用原版地砖像素。逐件处理和哈希见 PNG 旁的来源记录。

实际解码两张导出图，全部像素 alpha 为 255。两方向各检查 5001/5001、5001/5019、5019/5001、5019/5019，160 像素边的 RGB 逐像素相等。水面01以 1200×1040 像素预览，195 格底面中由透明度导致的透底像素从 1,222,168 降至 0。只比较未被上层图元覆盖的格边，两张地砖混排时各方向的平均 RGB 跳变从 9.68–29.11 降至 0.07–0.16，格边相较向内 3 个逻辑像素处的亮度差从 +52.48–+69.11 降至 −5.89–−1.20。详细样本数与计算口径见[新版预览来源记录](../assets/maps/previews/source-1-ground-pair-v2-candidate.png.provenance.json)。

按运行清单复查水面族 28 张图和 8,347 条绘制命令，5,430 个实例使用修订图元。水面01的 316 条绘制命令只替换 195 条底砖的文件引用。行列、三层格值、占地、偏移、碰撞投影及出生组核对通过，相关地图测试 15 项通过。现有顶部珊瑚裁切、其他图元可见轮廓、目标原版渲染原点、实机缩放和全族美术终验仍待完成。
