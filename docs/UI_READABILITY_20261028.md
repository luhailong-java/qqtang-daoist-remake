# 当前UI中文可读性调整

10月28日实际打开当前登录页时，说明与小标签偏小。静态复核发现 `src/styles.css`在多个视口把文字降到6–11px；本次将323处该范围的字号声明提高到12px，正文基准仍14px，主次按钮、筛选、导航使用14px。人物属性栏的中文标签和数值列同步加宽，页脚／说明允许换行，小屏保留12px说明。

这是UI排版修改，未改变地图行列、格距、占位、原图尺寸、碰撞或角色世界坐标。没有启动服务、构建或测试；当前本机资源时段尚未交还。必须恢复后在1920×1080、1440×900、1280×800、768×1024、390×844检查：登录四角色、长昵称、频道、八席、属性条、地图设置、聊天、模态框、战斗HUD与触屏控制的换行／遮挡／溢出。源数据和静态CSS存在不能当作通过。

已知风险：提高字号可能暴露旧固定宽度、紧凑网格和按钮高度的问题；检查时修布局，保留可读字号，不通过缩小文字消除溢出。未取得整页截图或全状态验收，保持pending。
