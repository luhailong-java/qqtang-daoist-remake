# 手游美术方向补充

2026-11-12（America/New_York）。用户新增目标：继续按现有道家 Q 版高清手绘风格改图，为后续手游使用准备素材。本补充承接[既有需求锁定](USER_REQUIREMENTS_LOCK_20261026.md)。

- 延续玉绿、象牙米白、暖金与现有原创角色身份。逐件保留真实生成来源、实际可得模型/质量证据、SHA256 和导出参数；未知证据如实标注。
- 原样本只读取证，原创改图保存为独立资产，来源链保持可追溯。
- 保留高清母图；RGBA 透明导出、源逻辑画布和 `rawOffset`／`frameOffsetRaw` 分别记录。等比派生不替换原始规格，不通过拉伸改动源相位。
- 32／48／64 像素预览仅用于小尺寸辨识诊断，保留透明边与等比例；预览尺寸不回填地图尺寸、格数、占地、碰撞、锚点或原偏移，也不计为新的美术数量。
- 不使用 computer use、CUA 或其他 GUI 自动化。画风、动作实速、界面和游戏效果交由用户手动审核，未审核候选保持未接受、未运行采用。

后续手游实现细节以真人另行明确的要求为准。

小尺寸诊断脚本为 `scripts/preview-head-world-mobile.py`，显式指定 `--item ID --manifest 路径 --output 新PNG路径`。只读取所选物品，按 SHA256 去重，生成 32／48／64 最大边浅深双底板及 `.png.source.json`；不放大低分辨率原图，记录每个原 PNG、源逻辑/偏移及实际缩图尺寸与比例。诊断输出不构成手游尺寸、挂点或美术验收。

本轮 407／2000 原像素审核板可用 `docs/art-review-20261112b/build-candidate-contacts.py`，同样显式指定 `--item`、`--manifest`、`--output`。源 PNG density4 原样在米白／深青左右展示，不缩放、不镜像；2000 为保留原像素允许更宽的审核板。板内标签和来源记录保留相位、别名、实际尺寸、摆放坐标与哈希，输出保持人审待定。
