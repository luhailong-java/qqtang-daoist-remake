# 四时山水库存缩略图

本批以道家 Q 版手绘重新表现四季、云海和林径。六件库存缩略图均为 256×256 RGBA，画面有意铺满方形，alpha 恒为 255。蓝色原库存边框已从原创构图中省去。

社区客户端中的原库存图均为 56×53。实际成员、原生帧偏移、解码图和来源哈希见[源记录](source-contract.json)及[源图拼版](references/source-six-board.png)。本批以库存图的风景主题为参照，所选成员均为 `res/uiRes/icon/bg/` 内的库存图。

原创母图为内置 imagegen 返回的 1536×1024 RGB PNG，实际模型和质量字段未披露。每格四边内收 8 px 后，从 496×496 正方形等比例缩放到 256×256。32 px 下海星和小亭退成色点，六个缩略图主要靠水岸、金色曲径、木屋、云带和苔石的大形辨认。见[生成记录](four-seasons-a-v1.png.generation.json)、[实际提交提示词](four-seasons-a-v1.prompt.txt)和[技术检查](verification.json)。

本批提供 395 个 bg ID 中的 6 件库存候选。用户视觉审核及游戏接入待进行，档案中的背景站立资源也待单独制作。见[库存清单](art.json)、[256 px 预览](contact-native-256.png)和[32、48、64 px 预览](contact-mobile-32-48-64.png)。
