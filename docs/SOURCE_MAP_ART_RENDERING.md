# 源地图与候选美术接入

2026-10-26。目标按 `USER_REQUIREMENTS_LOCK_20261026.md` 执行。地图数据和表面美术分别保存，当前没有原版身份或整图美术通过声明。

`src/original-maps.js` 读取已静态导出的三层格值、元素完整占地、方向属性、耐久、出生组及目标数据。原始字节重建与377张源map逐张哈希相等。源包属于社区修改后客户端，目标腾讯历史版本仍未确认。未知元素、越界占地和不合法出生点明确拒绝，不能自动改成空地或随机地图。

`src/map-art.js` 按元素ID查找 `assets/maps/runtime-manifests.json` 中列出的自有候选。每件保存原帧宽高、完整占地和源偏移；高分辨率导出不修改这些数据。当前视觉位置采用候选公式 `anchor * 40 - mapElem.imageOffset`，40逻辑像素仅有社区依据，尚未与目标原客户端渲染对照。图层2先绘，其余对象按完整占地底边与人物交错排序。缺图保留缺失状态，已破坏实例停止绘制，不用通用石块代替。

中国城01为15×13格、四人，逻辑区域600×520。画布固定2倍绘制密度，物理像素1200×1040，再等比适配视口；大图按文件头真实宽高使用动态比例。界面重排不改变地图行列、格值、出生坐标或碰撞。角色画法使用既有64单位绘制空间缩放到40单位；这属于当前显示候选，角色与原版的最终相对尺度仍需验证。

美术目录只预读JSON。切换地图时仅解码该图需要的PNG，同时最多四张；重复请求共用同一Promise，加载失败缓存并给出重试，不逐帧重发。非当前地图缓存预算64MiB；当前地图实际所需图片保留，不把预算当成已实测的总内存上限。人物静态运行图为1024×1024，身份4096原图仍保留作制作来源。

`server/map-catalog.mjs` 验证逐件PNG哈希，目录返回当前候选覆盖和缺失ID。界面禁用缺少场景美术的地图，以及规则、数据未支持的地图；全候选覆盖只意味着可供内部预览，不意味着完整美术通过。`geometryAccepted` 与 `accepted` 当前仍为false。

静态预览由 `export-map-art-preview.mjs` 和 `compose-map-art-preview.py` 使用实际候选PNG与运行绘制清单合成。它是图像装配检查，不是浏览器截图。源参考像素仅用于结构、透明遮罩或明确的几何取样；新地面、水面、建筑使用新画面，具体生成与派生操作逐件记录。
