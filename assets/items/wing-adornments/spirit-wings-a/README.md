固定社区客户端档案中的库存成员、原始帧尺寸和偏移均可逐项追溯。画稿省去了原库存图中的椭圆投影，保留了 25 的相连蝶身、26／27／111／133 的中缝和 147 的 U 形开口与底部连接。见[源记录](source-contract.json)和[原样参照板](references/source-six-board.png)。

母图格边界的最大 alpha 为 1，导出可见内容至少留 16 px 边距。五处开口测点 alpha 为 0–2，两个连接处 alpha 为 252–253。逐图重放裁切和等比缩放得到相同 RGBA 像素。

按实测轮廓宽高比，去除椭圆投影后，25 较源图宽 11.08%，26、27、111 分别偏窄 12.15%、11.18%、18.03%，133 偏窄 4.75%，147 偏宽 1.05%。26 在 32 px 深玉底上仍能辨认红色翼边，深色翼膜对比偏弱。轮廓比例和小尺寸对比度纳入视觉复核。见[逐项检查](verification.json)、[双底 256 px 预览](contact-native-256.png)和[32、48、64 px 预览](contact-mobile-32-48-64.png)。

源目录的 146 个 fpack ID 中，本批提供 6 件静态库存候选，余 140 件待制。待用户审核，佩戴图、挂点及原时序仍待核验。见[库存清单](art.json)。
