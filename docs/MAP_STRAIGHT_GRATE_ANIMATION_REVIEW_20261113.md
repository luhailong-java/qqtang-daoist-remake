# 直轨铁网机关逐帧审图

17130–17133 四组直轨机关各补齐十个源帧位。两张原创底图沿用黛石板、旧铜轨和深灰铁网，分别用于纵向与横向运动。将底图中的石板、铁网和轨道裁成条带，并按源帧里实测的相位导出。方格孔内为深色实像，整格保持不透明。

四组分别从用户提供的 QQTang-Local 对应社区 v1.3.4 地图资源解码。每组的十张源帧均为 40×40，帧偏移和地图元素偏移均为 `[0,0]`，占地一格。用解码后的 RGBA 字节确认反序对应，再让两套原创美术逐帧沿用相同的对应关系。每帧提供 40×40 和 160×160 PNG，共 80 个文件、40 种不同文件内容。输入图、实际提示词、原始输出哈希、裁切参数和逐帧像素复核均随图保留。 [QQ 堂来源记录](QQTANG_REFERENCE_SOURCE.md)
