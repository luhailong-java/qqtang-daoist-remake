V1 仅有提交证据，宿主输出未核实。V2 由内置 imagegen 重新生成，1536×1024 RGBA 母图、原样参数和工具返回均可核对。实际模型和质量未披露。见[V1 提交记录](hats-g-v1.png.generation.json)、[V2 生成记录](hats-g-v2.png.generation.json)和[V2 原样提示词](prompt-v2.txt)。

母图实际最大可见尺寸 445 px，最小格内留白 32 px，分别未达到提示词中不超过 400 px、至少 48 px 的目标。六个格边缘 alpha 最大为 2，指定开口样点 alpha 为 0 或 1，完整图形均能按原 512 px 格无切断导出。六张 256 px PNG 四周均留至少 16 px 透明边，源档案成员和导出像素重放核验通过。见[验证记录](verified-batch.json)。

外观待审核，人物佩戴与动画相位待制作。见[双底 256 px](contact-native-256.png)、[手机尺寸预览](contact-mobile-32-48-64.png)和[库存清单](art.json)。
