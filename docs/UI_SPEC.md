## 原版地图几何为固定数据

逐张核实并记录目标历史版本、原始地图名／ID、来源URL或本机文件、SHA256、像素宽高、格子宽高、行列数、分层／遮挡、建筑／障碍／出生点和碰撞坐标。原件、同版本数据或可靠资料缺失时标“待核实”，不以截图估测或自定数值补齐。

原始与重制地图的宽高、行列和格子规格必须相等；建筑、障碍、入口、道路、出生点及碰撞／导航坐标集合必须一致。建筑保留结构、用途、轮廓关系与摆放，用image画法重绘，不能改占地、通道、入口或遮挡。美术完成与几何通过分别验收。

屏幕适配只能对既定地图做等比例视口呈现。不得随手机或桌面重排地图数据，不得非等比拉伸，不得改变角色与地图的相对尺度。旧15×13随机地图和自定 `courtyard/town/factory` 摆放仅属待替换试稿，不是可接受的原版地图合同；即使原件最终恰有相同行列，也需逐格数据证明。

地图证据及缺口见 [QQTANG_MAP_DIMENSION_EVIDENCE.md](QQTANG_MAP_DIMENSION_EVIDENCE.md)。当前已静态导出社区样本377张map、381目录项与721元素，逐文件重建哈希一致；这是数据无损导出的证据，腾讯原件身份、目标历史版本、像素格距／锚点及完整运行投影仍待核实。327张为15×13，另50张有更大尺寸，不能统一规格。在同坐标美术替换与逐图差分验收完成前，不能宣称任何地图已1:1还原。

## UI与联网流程

本地身份 → 区域／频道 → 大厅房间列表 → 创建／进入房间 → 角色、队伍、地图、准备 → 对战／探险 → 结算 → 回房。区域频道是本地服务的组织方式，不代表腾讯原服务器在线。技术实现采用HTTP请求和SSE快照，服务端权威执行状态；客户端只发送操作，不上传自算坐标、速度、伤害、计分或胜负。

每房最多八席。同机多标签使用独立 `sessionStorage` 身份；房间、会话在内存中，重启清空。房主配置、开关空席、开局及暂停的权限、其他真人准备、断线保留与重连等按 [NETWORK_API.md](NETWORK_API.md) 的当前实现核验。失焦释放本机按键，不替其他玩家自动暂停。

桌面横窗：大厅左侧房间、右侧玩家／人物和聊天；房间4×2八席、右侧地图／规则／人物、底部聊天及准备／开始。状态读取真实服务快照，明确真人、AI、房主、队伍、准备和锁席；错误、断线、满房、未准备与无权限需有中文反馈。

按钮包含默认、悬停、按下、焦点和禁用状态，模式／地图／人物／频道／队伍明确选中。输入框聚焦时不触发游戏操作，弹窗处理焦点与关闭。方向键、空格与道具操作对照原版；WASD和触屏仅为输入适配，不改变游戏规则。商城是本地试穿，无Q币支付或真实发货。

界面可验证1920×1080、1440×900、1280×800、768×1024、390×844，窄屏允许界面重排和纵向滚动，但地图坐标与相对尺度保持固定。具体通过情况留在 `docs/VALIDATION.md`，不能以UI无溢出替代地图几何验收。

## 机制与技术试稿状态

已有 `classic`、`brawl`、`bun`、`soccer`、`push`、`adventure` 六个技术分支，分别对应普通竞技、比武、抢包山、热血足球、推箱子、合作探险。每个模式须单独核对原版操作、物件、计时、营救／补刀、复活、计分与胜负；热血足球不能改成球门进球玩法，特色模式不能仅换标题。

历史资料的5秒糖泡／困泡、属性档位等目前是候选线索，未经原客户端逐帧验证。试稿中的速度换算、相邻格接触、得分阈值、复活、掉落、三波探险等不能再称为被用户接受的“重制约定”；必须有原版依据或保持待核实状态。未核实规则不因测试通过而转正。

四个人物展示槽位、六分支不代表原版全部角色、模式、地图或关卡。原版全流程、精确物品与经济、全部动作与关卡仍需相应证据及实现。旧20项技术测试、旧浏览器截图与旧包仅是历史，不证明最新原版一致性已达标。
