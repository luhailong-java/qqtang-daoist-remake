# 足迹与步行拖尾

《灵葫大作战》自有道家Q版足迹类资源；来源为固定社区样本 catalog 的 footprint 类74个商品。源名称和说明只作追溯，不能当作新增游戏规则；画法采用 image 两张已确认主参考。背包256×256图标与战斗世界帧分别制作、分别记录。此目录不复用源人物、紫卡或像素皮肤。

当前阶段先制作完整背包图标候选。每次最多明确选择6个来源，实际解码查看相应 inventory 图标；不存在的映射如实记缺失，不猜 object 编号。模型原图、逐图配置与真实未知值、提示词、来源SHA、派生裁区及256输出均保存。原生尺寸按实际返回，256导出为等比重采样，不称新模型绘制。透明边、最小显示、世界动画与游戏采用分开验收。

目标输出：`assets/items/footprints/art.json`、`icons/`、独立母图、`references/`和相邻生成／来源记录；预览在`qa/footprints-*-contact-256.png`。世界动作、方向、锚点、时序目前未完成；整款游戏未完成。
