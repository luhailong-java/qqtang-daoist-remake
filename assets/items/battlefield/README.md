# 对局拾取物独立命名空间

`art.json`按`sceneId`记录对局对象工厂ID，和上层`assets/items/art.json`的账号库存`itemId`分开。不能用库存item1的帽子覆盖对局scene1数量增益，亦不因名字相同混同实体/物品/模型/动作编号。

scene1–8、21/23/24/25/26/27/28/47/61/62共18项已有首帧master候选，对应17张不同PNG，保留各自原始frame尺寸、raw offset和完整源动画帧数。新图先按原帧4倍等比导出，PNG真实尺寸/透明/哈希/裁显链逐件记录。各源动画有6–8帧，当前首帧不代表全部待机或拾取动画完成，未接入对局。每件比较新图可见比例和源完整帧比例，超过10%明确警告，不用非等比拉伸消除警告。

功能类别取自固定社区commit的`battleengine/pickup.go`常量/处理；与原生函数的独立核对仍待进行。图像文件号关联为待核实候选。原像素只作结构/内容参考，新画未复制其RGB。两主风格和自有图标finish实际附在内置生图调用中；母图旁有逐图生成记录，实际型号/质量未披露，为null。

三张母图为 `pickups-a-v1.png`、`pickups-b-v1.png`、`pickups-c-v1.png`，各旁置generation记录。B的香瓶蝴蝶结与桃叶越过理想512格线，导出按实际空隙调整切格边界，避免截断或将桃叶混进扳手；这属于裁切，不是模型修图。21/23/24/25/27/28的社区scene→action编号另保留，不把其账号库存业务名套进来。

26与62的**完整源DIMG字节SHA相同**，不是凭名字相似猜测；62显式共享26的新图文件，`reuse/62-from-26.json`保留两者来源及独立scene语义，不重复生图。C只画5项，末格空白。47源包资源实际为大写 `Item47_stand.img`，来源记录保留真实大小写。
