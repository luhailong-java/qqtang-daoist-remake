## 固定边界

1. 玩法、规则、功能、操作与游戏流程以腾讯《QQ堂》原版为目标，不擅自以其他泡泡游戏、自定玩法或简化规则代替。
2. UI和人物使用我们自己的道家Q版高清手绘设计。角色的脸型、发型、轮廓、服装、名字和身份需要原创，不再强制沿用毛毛、阿莎、悟空、泰坦的识别外观，不仅是原角色换衣服。玩法属性与外观身份分开映射。
3. 地图逐张对应原版：逻辑宽高、行列、格子大小、地图像素尺寸、建筑位置与占地、道路、障碍物、出生点、碰撞和可通行区域需要有原版依据并一致。不自定尺寸，不加减行列，不重新安排建筑，不因屏幕宽高改变地图数据或角色与地图的相对尺度。
4. 建筑保留原版结构、用途、轮廓关系与摆放，采用image已确认的道家Q版画法、材质和配色重绘。新画法不能改变入口、通道、遮挡、占地或玩法几何。
5. 屏幕适配与地图原始规格分开。允许显示视口对既定地图做等比例呈现；地图数据、素材原始尺寸与碰撞坐标不得随屏幕重排或拉伸。

## 原版几何锁定与验收

每张地图先取得可核验的原文件、同版本数据或可靠资料，登记目标版本、原始地图名/ID、来源URL或本机文件、SHA256、像素宽高、格子宽高、行列数、分层/遮挡、建筑/障碍/出生点和碰撞坐标，再进行同坐标美术替换。尺寸未知、版本不明、仅凭截图估测的项均写“待核实”，不使用自定值补齐。

实际差分验收需要比较：原始与重制地图宽高/行列/格子规格完全相等，建筑与障碍占地及坐标集合一致，入口、通路、出生点与碰撞/导航数据一致；美术单独检查道家Q版风格和原创人物。不得用放大、裁切概览、重排截图或程序摆箱声称原版地图已完成。
