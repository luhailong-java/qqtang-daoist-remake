# 玉纹操作图标

四个 128×128 RGBA 图标可用于当前的开始、暂停、关闭和下一步控件。图形为右向三角、双竖条、斜交叉和带柄右箭头，共用深青玉、暖金细框和象牙色符号。见[清单](manifest.json)。

内置 imagegen 返回 1254×1254 RGBA 原生母图，调用时请求 1024×1024，实际按四个 627 px 格切片。透明格边 alpha 最大值为 1，四张导出图至少留 8 px 透明边。裁切、等比缩放和双底预览的像素重放均通过。见[生成记录](actions-v1.png.generation.json)、[原样提示词](prompt-v1.txt)及[验证记录](verification.json)。

米白和深青玉背景均提供 16、20、24、32 和 128 px 预览。16 px 时下一步箭头的短柄较弱，和播放同为右向符号。开始和下一步应保留页面上的文字提示。预览可用于实机人工审核。见[双底尺寸预览](contact-16-20-24-32-128.png)。

现有全屏和静音图标分别见[全屏](../semantic-extra/fullscreen.png)和[静音](../semantic-extra/mute.png)。
